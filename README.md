# СВОДКА — витрина финансовых предложений

Одностраничный сайт-витрина под партнёрские (реферальные) ссылки банков и
МФО. Чистые HTML/CSS/JS без сборки, плюс панель управления каталогом на PHP.

Стиль взят из [finlist](../finlist) — клиент выбрал именно его — и сдвинут:
бумажный холст вместо серого, синий чернильный акцент вместо винного,
Golos Text + JetBrains Mono вместо Geist, двухколоночный первый экран со
сводкой по разделам вместо размытого заголовка, карточки с настоящими
логотипами банков вместо плоских плиток.

## Запуск

```bash
php -S 127.0.0.1:4660 -t /Users/openclaw/svodka
```

Есть конфигурация `svodka` в `~/.claude/launch.json` (порт 4660).
Панель — `/panel.html`, пароль лежит в `.pass-note` (в git не уходит).

## Что где

| Файл | Зачем |
|---|---|
| `index.html` | вся разметка страницы |
| `styles.css` | оформление, палитра в `:root` |
| `script.js` | каталог, фильтры, лента, вопросы, форма |
| `data.js` | **единственный файл с содержимым**: разделы и карточки |
| `panel.html` + `panel-*.js` + `panel.css` | панель управления каталогом |
| `api.php` | приём правок из панели, откат, смена пароля |
| `data.php` | отдаёт каталог мимо кеша браузера |
| `check.php` | страница «что сейчас на сайте» для владельца |
| `img/logos/` | логотипы 52 банков и МФО |
| `fonts/` | Golos Text и JetBrains Mono локально, интернет не нужен |
| `deploy.sh` | заливка на хостинг по FTP |
| `ACCESSIBILITY.md` | контрасты, решения по доступности, что осталось |

## Каталог

39 предложений в четырёх разделах: займы (15), дебетовые карты (9),
кредитные карты (9), кредиты наличными (6).

**Партнёрских ссылок пока нет** — поле `url` у всех карточек пустое. Пока оно
пустое, кнопка карточки ведёт на форму заявки, а над каталогом висит честная
строка «партнёрские ссылки ещё не подключены». Вставили ссылку — карточка сама
начинает открывать сайт партнёра в новой вкладке, а `erid` из ссылки сам
печатается строкой маркировки.

**Цифр в карточках намеренно нет.** Ставки, лимиты, кэшбэк и сроки даёт
партнёрка по каждому офферу отдельно. Писать их «на глаз» нельзя: это
недостоверная реклама, и отвечает за неё распространитель — владелец сайта.
Пришли условия — они вписываются в `headline` и `specs` через панель.

## Что нужно от клиента

1. Партнёрские ссылки из кабинета партнёрки — по одной на карточку.
2. Ник в телеграме для заявок (поле «Телеграм для заявок» в панели).
3. Домен и хостинг с PHP. Без PHP сайт работает, панель — нет.
4. Наименование рекламодателя и ИНН для маркировки рекламы, если партнёрка
   их выдаёт. Пока их нет, страница закрыта от поисковиков (`noindex`
   в `index.html`).

## Деплой

Доступы кладутся в `~/.svodka-ftp` (chmod 600):

```
FTP_HOST=...
FTP_USER=...
FTP_PASS=...
FTP_DIR=www/домен
SITE_URL=https://домен
```

```bash
bash deploy.sh              # сайт без каталога: data.js на сервере правит клиент
bash deploy.sh --with-data  # вместе с каталогом (первая заливка)
```

После первой заливки положить рядом с сайтом `.admin-pass` (хеш пароля
панели) — он в репозиторий не уходит. Сгенерировать новый:

```bash
php -r 'echo password_hash("новый-пароль", PASSWORD_DEFAULT), "\n";' > .admin-pass
```
